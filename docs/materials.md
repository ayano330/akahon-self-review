## 1. 方針

- **新しい問題集は買わせない。** 使えるのは、下の一覧と、解いた赤本と、直しノート
- **授業ノートが、生徒にとっての教科書。** 教科書・図説は、どうしてもわからないときだけ引く
- 先生が配信した授業動画の見直しは可。ただし時間がかかりすぎないようにする
- **YouTube や AI で調べない。** 教え方が変わるし、間違っていることがある
- わからないことは、先生に聞くのがいちばん早い
- 対象は高3。全範囲を履修してから赤本に入る

## 2. 使う教材

| 略称 | 教材 | 役割 | 終わりの目印 |
|---|---|---|---|
| ノート | 授業ノート | 授業の板書。知識の確認、仕組みの説明、授業で扱った計算・考察の型 | 声または文・図で、自分で説明できる |
| ミニテ | 今までのミニテ集 1〜4 | 授業のミニテストを冊子にしたもの。知識の定着はまずここ。1回約15分。100点満点(ときどき50点) | 予習なしで不意に解いても8割。ここまでで MARCH の基礎知識は入っている |
| 単元別 | 単元別問題集 1〜4 | ★1〜5。宿題は★1〜3。章によって分量差が大きい | ★3まで自信があれば MARCH の基本問題は OK |
| 論述 | 論述問題集(全単元1冊) | 定番論述が★1〜5。単元名は下の15単元と同じ | 地方国立なら★3まで自信を持って書けることが基礎 |
| バイテク | バイテク演習テキスト | 夏期特講(3日)用。遺伝子の発現のうち、パターン化できる計算・思考 | 脊髄反射で解ければ、MARCH の差がつく問題まで対応可 |
| 赤本 | 解いた赤本 | 入試本番の問題。直しの材料 | 間違えた内容をストックし、見直せる |
| 直しノート | 生徒が自作する直しノート | 赤本で間違えた問題のストック。授業にない知識は授業ノートへ追記 | 定期的に見直し・解きなおしできる |

### 使わない / 例外だけ使う

- 教科書・図説: 基本不要。どうしても理解できないときだけ
- 授業動画: 可。長く見すぎない
- YouTube / AI: 使わない

### 誰が持っているか

- **生徒全員が、全てのレベルの全ての教材を持っている**
- **バイテクだけ受講者のみ。** ほとんどの生徒は受講しているが、未受講に配慮する(遺伝子の発現の計算で、バイテクを前提にしない)

### ★の意味(単元別・論述)

| ★ | 誰に解いてほしいか |
|---|---|
| ★1〜3 | 全員。宿題の範囲。MARCH の基本 / 地方国立論述の基礎 |
| ★4 | MARCH より上位志望ならぜひ |
| ★5 | 旧帝・早慶(慶応看護を除く)・医学部なら解いてみてほしい |

## 3. 基本ルート

迷ったらこの順。飛ばさない。

**ノートで確認 → ミニテ8割 → 単元別★3まで → 上位校志望なら★4まで**

- 論述問題集は、論述がある大学を受ける生徒が使う(私立でも論述がある大学なら使う)
- バイテクは、遺伝子の発現の計算・思考で、特講を受けた生徒だけ足す
- 単元別は章によって分量差が大きい。約束の量は「1章全部」にせず、★と問題数で切る

## 5. タグごとの行き先

ツールの8タグとの対応。ここがアクション文の行先。

| タグ | 状態 | 行き先 |

## 6. 相談中(壁打ち用)

コードには入れない。決まったら上の表を更新する。

### 6-1. 考察 / 計算・処理

共通の分岐は「授業で同じ型をやったか」。

- やった → ノートの型を説明できるまで → その教材を解きなおす
- やってない → 解いた赤本のその問題で整理する → 直しノートへ。授業にない知識は授業ノートに追記

計算だけ追加の分岐:

- 遺伝子の発現のパターン計算で、特講を受けていればバイテク。未受講はノートの型に戻す
- 「解き方がわからない」と「立式できたが処理ミス」は、今の質問票ですでに分かれている

ツールに「授業でやった型か?」を1問足すか、全員に同じ文(まずノートを探す → なければ赤本)にするかは未決。

### 6-2. ケアレス / 時間不足

教材を開かない。次の赤本の立ち回りを変える。

今の下書きは、ケアレス=条件に線、時間=大問の目安時間。これ以上の場合分けを、質問に足すか、今の選択肢の文言直しで足りるかは未決。

### 6-3. 赤本と直しノート

間違えた問題は直しノートへ。授業で扱っていない知識は授業ノートに追加。大事なのはストックを作り、定期的に見直し・解きなおすこと。
