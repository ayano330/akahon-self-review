作成日: 2026-10-30
元資料: 他の生物科の先生へのヒアリング(ChatGPT による要約)。「という考え方もある」は少数意見として、既定にせず選択肢か見送りにした。

## 3. 「次への一手」のひな形(タップで選ぶ。「自分で入力する」も選べる)

対象は 考察・計算・ケアレス・時間不足。ひな形を選ぶと入力欄と約束の「やること」に入る。書き換えると「自分で入力する」に切り替わる。文は回答から取った。載せる文は先生が決める。

- 考察(問7): 先に設問を読む / 実験の目的とグラフ・表の意味を確認 / 実験群と対照群の条件に印 / 根拠を示して口で解説
- 計算(問8〜10): 途中式を省かない / 分数は小数を整数に直す / 単位を書く / 条件を図にする / 文字式は数字を代入 / 「いつものやり方なら」を書き出す / ミスした式を紙に記録して先生に見せる
- ケアレス(問11): 指定に線 / 「正しい・誤り・一つ・すべて」に丸 / 有効数字と求めるものを確認 / 注意を紙に書いて解く前に見返す
- 時間不足(問12): 飛ばして一周後に戻る / 選択問題は直感で解答して印 / 「単語・選択 → 計算 → 考察」の順 / ミニテ集の単語を繰り返す / まず丁寧に解く

## 4. 約束の「見直し」

約束の日を選ぶと「2〜3日後の見直しも、約束に入れますか?(任意)」(入れない / 2日後 / 3日後)が出る。入れると、約束の日から数えた日付で「見直し(○日後): ○○」が別の約束として入る。問3・問8で「2〜3日後に振り返る・解き直す」が出たため。知識不足の復習間隔(未決だった)の根拠にもなる。

## 5. 見送ったもの・要確認

- **見送り**: 「捨てる」の提案(問8・9・12)。「時間が少ないから省略しない」方針と衝突するため、先生の方針待ち
- **見送り**: 志望校や時期での自動出し分け(問3の東農・MARCH、問8の1月)。「志望校だけで振り分けない」方針
- **見送り**: 「まぐれ正解」を拾う入力(問4)。失点した設問だけ聞く設計のため
- **見送り**: AI に口頭で説明して判定してもらう(問4)。`materials.md` は「AI で調べない」
- **要確認**: 資料集(問3)。`materials.md` は「教科書・図説は基本不要」
- **要確認**: ノートの呼び名。MMノート・ミニノート・落とし穴ノート・単語カード(回答)と直しノート(`materials.md`)が同じものか。手順の文では「ノート」とだけ書いた
